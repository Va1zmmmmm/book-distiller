# 从材料准备到陪读

1. 确认书籍和版本、使用材料的权限，把章节依实际阅读顺序填入 JSON。运行 prepare，保留准备端在本地；没有模型响应也能先整理原文。
2. 检查摘要、概念和引文上下文，特别区分作者、人物、叙述者、序者和译者。quotes 的字面验证无法发现所有主体误读。
3. 根据自己真正读到的位置运行 session。只读了部分章就指定 through-line；把导出的包交给选定模型，先读 companion.md、session.json 和 START.md。附上本次真实划线或具体问题，不让模型假称看到未提供的划线。
4. 一次讨论一小段，不知道就停，允许问题悬而未决。确认进度由读者决定，工具不自动推进。模型如果剧透，停止使用相关解释，回到已读原句。
5. 用 note 将读者发言、AI 观察、待解问题和纠正分别登记；开启下次会话时重新导出已读范围。已有会话不会自动同步新笔记，需要新建导出目录。

全书准备和陪读是两个边界。全书准备可分析所有章节，读者会话只拿已读材料。部分章会舍弃该章完整分析和该章笔记，宁可少给导航；此前完整章的笔记仍提供，所以录入笔记时不要在早章事件里写入后章内容。

材料限制不能阻止模型从训练记忆提前透露内容，也不能保证它遵循节奏约定。首版提供准备、引用核验、导出和留痕，模型客户端的文件读取和实际对话效果由使用者验证。

未来优先补：通用 EPUB 导入与版本校验、行号更直观的选择器、结构化真实划线导入、真实提供商兼容测试与读者反馈。可视化和分享排版沿用下游项目，不将它们耦合为本工具必需依赖。
