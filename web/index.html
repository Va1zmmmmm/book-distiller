FOR THE THINGS THAT STAY

读完了。
有些什么，想留下。

一段感受、几句划线，或一个还没想明白的问题。
把它们放进卡片，回头再读；也给下一次陪读准备原文。

不用登录，不用安装。示例为原创虚构材料，预先整理，免费体验。

你的阅读材料01 → 02 → 03

书评是你的理解，划线是原文。它们会分开保存。

从文件或既有卡片继续

JSON 可导入标准卡片输入或本工坊草稿；TXT / Markdown 会放入读后感。最多 2MB。

AI 使用设置（可选）

只有点“让 AI 帮我提炼”才会把书评与划线发送到 DeepSeek 官方服务，由你的账户付费。密钥只保留在此页面内存，关闭页面后消失。

没有密钥也可以本地排版。模型返回不合格式或引文不符时保留原卡，不替你拼凑结论。

留给未来的自己

卡片不必装下一本书。
留下你愿意留下的就好。

逐条看，留下自己接受的部分

修改区是你的文字。原始输入和 AI 候选会随草稿保留，不会被改写。

BRING THE TEXT, THEN TALK

陪读之前，先把原文备好。

导入自己有权使用的书，确认版本与位置，再导出已读材料给你常用的 AI。

文件在浏览器内读取，不上传。最多 30MB / 150万字；扫描 PDF、加密书籍暂不解析，提取结果需回看原文件。

“完整备料”含全书原文，只供自己准备。陪读导出不含后章标题、目录或原文。
