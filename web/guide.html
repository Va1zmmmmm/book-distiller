第一次做卡片

  1. 点文学或方法书示例，立即看到一张预先整理的原创卡片。
  2. 换成自己的书名、感受和划线，点“把我的文字排成卡片”。它只排版，保留你的原话。
  3. 逐条看，修改或删掉不接受的部分。勾选愿意分享后，导出图片或文字。长卡片自动分页，下载为 ZIP。
  4. 离开前保存草稿，下一次从“从文件或既有卡片继续”导入。网站没有账号，也不会替你自动保存。

需要 AI 时

可以下载提示词与材料，交给自己使用的 AI，把它返回的 JSON 粘贴回来。也可以选择用自己的 DeepSeek API 密钥直接提炼；调用由自己的账户付费。跨域或网络限制可能阻止直连，可改用提示词方式。示例不需要密钥。

核验检查格式、依据编号、逐字引文，不判断解释是否正确。没有根据的用途不应硬写；文学作品可以留在意象、感受或未解问题上。“确认分享”代表你愿意分享当前文字，不代表程序证明了观点。

整书与陪读

导入你有权使用的 EPUB、文字型 PDF、TXT、Markdown 或标准 JSON，核对提取内容、书名、译者与版本。EPUB 按阅读顺序、PDF 按页提取。选择已经读到的章/页和行数，导出原文及陪读规则，再提供给自己选择的 AI。网页不会自动发送书籍或聊天。完整备料 JSON 可继续交给命令行版做逐片段分析。

陪读导出不附后章标题、目录、原文或分析；模型仍可能从训练记忆剧透，不能保证完全无剧透。扫描 PDF 没有 OCR；加密 EPUB 不解密。PDF 双栏、脚注、字体、复杂排版可能影响顺序或文字，需对照原文件。不完整提取会报错，不静默忽略空白页。文件上限 30MB、解压上限 60MB、正文 150万字。

隐私与下载

解析、排版、导出均在浏览器完成。材料、草稿和密钥不写入网站存储，不使用 localStorage、分析追踪或广告。只有你点直接 AI 提炼时，卡片书评与划线会发给 DeepSeek 官方 API；整书不会随之发送。服务提供商对发送材料的处理以其政策为准。

下载的草稿包含你的原始材料和候选，完整备料包含全书，请自行保管。分享图片或原文时，请检查个人信息和引用范围。公开代码与原创示例不包含你的书籍。

建议使用更新的 Chrome、Edge、Safari 或 Firefox。小红书内置浏览器若不能下载，请用系统浏览器打开。PNG 多页包需要先解压。源代码：GitHub。
